# معرض أعمال — لوحات Power BI / تحليل الموارد البشرية

مشروعان مستقلان ببيانات اصطناعية مختلفة، لعرض مهارة تحليل بيانات الموارد البشرية وبناء لوحات تفاعلية:

- **project-1-tech/** — شركة تقنية واتصالات (260 موظف، 7 أقسام)
- **project-2-manufacturing/** — مصنع صناعي (300 موظف، 8 أقسام، تركيز على السلامة المهنية)

## محتوى كل مشروع
- `data/*.xlsx` — بيانات الموظفين الاصطناعية + شيت ملخص بصيغ `COUNTIFS` تلقائية.
- `dashboard.html` — لوحة تحكم تفاعلية جاهزة (فلاتر + رسوم بيانية)، تفتح مباشرة بأي متصفح بدون تثبيت شيء.
- `README.md` — شرح البيانات + رابط اللوحة المباشر + خطوات اختيارية لإعادة بنائها في Power BI.

## لعرض اللوحة كرابط مباشر بعد الرفع على GitHub
فعّل GitHub Pages من إعدادات المستودع (Settings > Pages > Deploy from branch > main)، بعدها `dashboard.html` في كل مشروع يصير له رابط عام دائم تقدر تشاركه.
